campscore는 기상청 api의 중기예보와 캠핑장의 평가를 종합하여 적합한 점수를 매겨 추천을 해주는 것을 목표로 계획된 프로젝트였습니다.

원래는 RestAPI 기반으로 제작하려했지만 저와 팀원들의 미숙함으로 인해 불가능했고 마감기한에 쫒겨 핵심기능 상당수가 잘려나갔습니다.
html 파일은 RestAPI 기반으로 제작하려했던 흔적으로 프로젝트는 jsp로 작성된 프로젝트라 봐도 무방하니 해당 기능을 참조해주시면 좋겠습니다.
캠핑장 정보는 카카오 맵api로 수집, 별도의 DB에(mysql) 저장하였기에 별도로 DB를 작성하여 값을 넣어주셔야 합니다.
컨트롤러에 기상청api 키와 카카오 맵 api키를 포함시켜 놓는 실수를 범했으나 두 키 모두 만료되었을 것입니다.
